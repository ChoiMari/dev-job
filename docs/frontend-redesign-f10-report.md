# F10 최종 검증 결과 (2026-10-11)

기준: `frontend-redesign-implementation-plan.md` 5절 G1~G6 및 `frontend-redesign-requirements.md` 5절. 이 보고서의 **통과**는 이번 F10에서 직접 실행한 범위에만 적용한다. F09의 정적 연결 대조와 이전 단계의 검증은 별도로 표시한다.

## 실행 환경과 수정

- Windows, Node.js 24.19.0, pnpm 11.25.0. `pnpm install --frozen-lockfile`로 lockfile의 의존성 24개를 복원했다. 생성된 `node_modules`와 `dist`는 Git 추적 대상이 아니다.
- Vite `http://127.0.0.1:5173`과 로컬 Backend `http://127.0.0.1:8080`의 `GET /api/auth/me` 401을 브라우저 및 HTTP로 확인했다. Backend의 DB가 일회용 격리 DB인지 확인되지 않았고 Docker 데몬도 실행 중이지 않았다. 따라서 데이터 변경을 수반하는 계정·CRM·문서·삭제 호출은 실행하지 않았다.
- 최초 브라우저 검사에서 미인증 `GET /api/auth/me`의 401이 전역 세션 만료 이벤트를 발생시켜 공개 홈 대신 `#/login?sessionExpired=1`로 이동했다. `authApi.me`를 기존의 조용한 `sessionProbe` 경로로 바꾸고 회귀 테스트를 추가했다. 재검사에서 `#/` 공개 홈, CTA의 `#/login`·`#/register` 이동이 확인됐다.

## 요구사항 완료 판정

1. A01~A22 UI 연결은 F09 정적 대조상 105/108이며, 남은 3개는 운영·대체 경로로 이유가 있다. 모든 메서드의 실제 동작 확인으로 판정하지 않는다.
2. P00~P20의 기본·로딩·빈·오류·저장·좁은 폭 상태 전체 검증은 **미완료**다. 이번 브라우저 확인은 P00/P01의 공개 접근과 지정 폭에 한정된다.
3. 공개 홈→인증 화면은 통과했다. 대시보드 이후 G2/G3 전체 흐름은 **미완료**다.
4. 이번 수정은 세션 조회 경로만 바꿨고 Backend·DB·REST 계약과 UI 명세의 동작 정의는 변경하지 않았다. `docs/ui-spec.md`와 API 명세의 수정 필요 사항은 발견되지 않았다.

남은 검증은 일회용 PostgreSQL DB, 검증용 계정, 필요한 암호화 키/외부 서비스 모의 또는 격리 설정을 갖춘 Backend에서 수행해야 한다. 현재 8080 서버는 실행 중이지만 소유 DB를 확인할 수 없어 변형 요청을 보내지 않았다. 기존 Playwright 흐름 스크립트는 모듈 설치 경로가 제공되지 않아 실행하지 않았고, 공개 화면 검사는 Codex 브라우저로 직접 수행했다. **F10 전체 완료로 표시하지 않는다.**

## 미검증 항목 재검증 (2026-10-11)

이 절은 위 최초 실행의 미검증 판정을 갱신한다. 로컬 `postgres:17` 일회용 컨테이너의 `devjob_f10_test`에 Backend를 연결했다. Flyway V1~V26과 JPA 검증을 거쳐 Backend가 8098에서 시작했고, Vite의 `/api` 프록시는 이 Backend를 사용했다. 외부 AI 및 ALIO 키는 주입하지 않았다. 테스트 계정·데이터는 이 DB에만 만들었다.

| 범위 | 실제 결과 | 남은 제한 |

브라우저 자동 승인 검토는 이력서 원문을 외부 AI 분석 서비스로 전송할 수 있다는 이유로 `동의 후 분석 요청` 클릭을 거절했다. 테스트 문서라도 특정 원문과 외부 목적지에 대한 명시적 승인이 없으므로 다른 호출로 우회하지 않았다. 기존 `f03-viewports.mjs`는 현재 브라우저 흐름에서 첫 공고 화면 제목을 찾지 못해 제한 시간 30초에 실패했으며, 위 52개 화면 크기 검사는 Codex 브라우저에서 별도로 수행했다. 수집 공고·차트의 데이터 상태와 외부 서비스 오류/부분 실패는 추가 fixture 또는 모의 제공기관이 있어야 검증할 수 있다. 따라서 G1~G6 및 요구사항의 **전체 완료 판정은 여전히 보류**한다.
