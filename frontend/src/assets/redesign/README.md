# Redesign image assets

새 프론트 디자인을 위해 생성한 장식 이미지 26개와 DEVJOB 로고 2개를 이 폴더에 둔다. 제작 기준과 에셋 ID는 `docs/image-generation-brief.md`, 실제 파일명·크기·사용처·검증 결과는 `docs/redesign-image-manifest.md`를 따른다.

기존 `frontend/src/assets/illustrations/`의 장식 파일을 이동·덮어쓰지 않는다. 실제 화면 연결은 해당 기능의 UI 작업에서 진행한다. `cur-10-character-sheet.png`는 제작 기준용이며 UI에 통째로 배치하지 않는다. `ext-img-*`는 확장 기능 구현 전에는 화면에 노출하지 않는다.
